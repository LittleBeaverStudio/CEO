使用说明

三步用起来

1️⃣ 导：「导入」页三个文件槽——银行流水（Excel/CSV）+ 我开出的发票（必导，算谁欠你）+ 我收到的发票（可选，算你欠谁）；先选文件再点「导入」。
2️⃣ 填：录入每月固定支出（工资/房租/税，填上「每月几号」方便对账）；缴税/分红/设备等一次性大额支出，在「设置 → 固定支出」按具体日期记一笔。
3️⃣ 看：回到「驾驶舱」——先看一句话速览和本周要办，再按需下钻现金跑道、应收/应付、支出结构与大额支出；发票带项目字段会多一张项目盈利卡。
4️⃣ 警：中性场景预计跌破安全线或撑月数吃紧时，跑道卡与速览卡会出现预警；可在「智能助手」让 AI 归因。
5️⃣ 问（可选）：配置云 LLM API 后可用自然语言问看板、生成周简报并一键推企业微信；未配置则是本地规则模式。内置 DeepSeek / Kimi / 智谱 GLM / MiniMax / 通义千问 / 豆包 / 硅基流动 / OpenAI / 本地 Ollama 预设，选厂商填 Key 后点「测试连接」即可验证。

口径说明（经营口径不是会计口径）

· 应收（别人欠我） = 开具发票 − 银行已收（按 对方 + 金额 + ±90 天日期窗口 轻匹配）；没匹配上的开具额全部算未收回。
· 应付（我欠供应商） = 取得发票 − 银行已付，同样轻匹配；是"还要往外掏的钱"的估计。
· 还能撑几个月：把账上现金按三场景回款假设往下推演，现金首次见负的时点（月内插值）；并列给中性/最差两个数，不给单点结论。
· 支出结构：按摘要/对方关键词把近 6 个月支出归入 人力/场地/税费/财务/平台推广/其他 六个大类，认不出的进"其他经营支出"，仅供参考。
· 本周要办：由撑月数、安全线、账龄、应付账期规则生成，AI 只解释不改变结论。
· 金额单位：元（列至角分），KPI 主显万元；本页配色遵循红=风险/流出、绿=健康。
· 银行流水与发票明细长期累积存储（像日记账/台账），重复导入自动去重；原始文件可在两个台账页随时查。

往来单位关联（同一家公司的两种名字）

· 发票抬头写「B 公司」、银行流水对方写「A 公司」，实际是同一笔业务（A 付款、B 开票）。
· 到「设置 → 往来单位关联」：左格填 A（要并入的名字），右格填 B（驾驶舱要显示的名字），点「关联」。
· 之后应收/应付按同一家合并计算，不会拆成"一笔欠款 + 一笔欠票"；台账里仍显示原始名称，只影响驾驶舱口径。删除关联即恢复原样。
· 本公司自己出现在发票"对方"字段的行，会自动排除在应收/应付之外。

AI 接入（可选）

· 不配也能用：决策卡、周报、告警走本地规则模板。
· 要自由问答就选厂商（内置 DeepSeek / Kimi / 智谱 GLM / MiniMax / 通义千问 / 豆包 / 硅基流动 / OpenAI / 本地 Ollama / Agnes）、填 Key、点「测试连接」。
· 模型列表可点「刷新模型」从厂商实时拉取；默认把真实客户名发给 AI，勾选「隐藏客户名称」则改用 客户A/B 代称。
